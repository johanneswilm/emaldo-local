Day schedule (96 quarter-hour slots)

Written to the module as the vendor set_override command (0x1a) — the same command Home Assistant's optimizer uses. Slot 0 is 00:00 local; slot n is n·15 minutes after midnight. A second set of 96 covers the following day, which is what the vendor app does.

Work mode and reserve

E2E 0x19. The high/low markers ride along on every write, so they are read back first.

    Operating mode

    Local: the vendor domains resolve to this box and the vendor app runs against the bridge. Vendor: the pins are removed and the bridge's cloud leg passes traffic through, so the app resumes its original cloud path. Either switch is one command and reversible; the app is never disabled.

    Cellular (LTE)

    The vendor app dials the built-in LTE modem as a fallback path. While the unit runs local, that path is closed (modem unbound from USB, pppd stopped, interface down) because it is the only way to reach the vendor cloud and the radio is not paid for. Restoring puts the modem back on the bus; the app redials by itself.
